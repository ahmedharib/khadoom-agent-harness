# KNet Payment Gateway Guide

KNet is the national debit card payment gateway exclusively for merchants operating in Kuwait (`KW`) using the Kuwaiti Dinar (`KWD`).

## Requirements and Activation
KNet is only available for stores configured with `KWD` currency and a licensed Kuwaiti commercial registration. Stores using `SAR` or `AED` should use Mada or local GCC gateways instead.
